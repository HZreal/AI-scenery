# 03. 工具调用 / Function Calling

## 学习目标

让模型安全地调用后端确定性函数，完成查询、计算或写入草稿等任务。

## 核心要点

- 工具 schema 与参数描述。
- 参数校验和错误反馈。
- 工具调用重试。
- 工具权限边界。
- 模型输出与真实执行结果的分离。

## Demo 方向

`demos/03-tool-calling/`

实现一个 Agent 调用本地工具完成后端任务，例如计算价格、查询资料或生成草稿。

## 验证场景

- 合法参数能成功调用工具。
- 非法参数被拒绝并返回明确错误。
- 工具失败时保留错误信息和 trace。
